## 살아남은 전략

```
점수 = 0.45×(MA20 > MA60) + 0.35×(슈퍼트렌드 10,3) + 0.20×(MA50 > MA200)

점수 < 0.5  →  비중 0%
점수 ≥ 0.5  →  비중 = 점수 (55 ~ 100%)
```

**비교기준** BTC 70 / ETH 30 단순보유 · **수수료** 편도 0.25% ·
**리밸런싱 밴드** 10% · 재현: `python3 backtest.py --portfolio`

| 기간 | 전략 | 단순보유 | 전략 MDD | 보유 MDD | 평균 노출 |
|---|---|---|---|---|---|
| 2020-08 ~ 2026-08 (6년) | **541%** | 430% | **−40%** | −77% | 46% |
| 2022-01 ~ 2026-08 (2021 제외) | **52%** | 10% | **−36%** | −68% | 41% |
| 2023-08 ~ 2026-08 (3년) | 66% | 87% | **−36%** | −56% | 46% |
| 2025-08 ~ 2026-08 (1년) | **−6%** | −45% | **−21%** | −57% | 26% |

낙폭은 네 기간 모두 절반 안팎으로 줄었다. 수익은 기간에 따라 갈리는데,
3년 구간에서는 뒤진다. 상승장에서 뒤처지는 것이 이 구조의 정상 동작이다.

**out-of-sample 검증** 파라미터 선택에 쓰지 않은 2017~2020 구간에서 재현됐다
(BTC 3.30x vs 보유 2.86x). 슈퍼트렌드 파라미터는 period 7~20 × 배수 2.0~4.0
격자 20칸 모두 개선. 다만 종목 축은 8종 중 3종만 통과해 범용 전략은 아니다.

### 문서 숫자 정정

2026-08-06, 채택 전략 백테스트를 레포 안에 만들면서(`backtest.py --portfolio`)
이전 판의 6년 행이 재현되지 않는 것을 발견했다.

| | 이전 판 | 실제 (BTC 70 / ETH 30) |
|---|---|---|
| 전략 | 876% | **541%** |
| 단순보유 | 1,019% | **430%** |
| 전략 MDD | −38% | −40% |
| 보유 MDD | −76% | −77% |

원인은 **SOL 오염**이었다. 배분을 바꿔가며 맞춰보니 `BTC 50 / ETH 30 / SOL 20`
이 보유 1,080% / 전략 1,157% 로 이전 판에 가장 가까웠다. SOL 은 배분에서
제외하기로 한 종목인데 표에는 남아 있었던 것이다.

두 가지가 남는다.

- **MDD 는 영향받지 않았다.** 전략의 근거인 낙폭 축소는 그대로다
- **결론은 오히려 강화됐다.** 이전 판은 "876% 대 1,019% 로 뒤진다"였는데
  실제로는 6년 구간에서 **541% 대 430% 로 앞선다.** 낙폭을 절반으로 줄이면서
  수익도 밀리지 않았다

교훈은 이 문서가 이미 적어둔 것과 같다 — **표를 만든 뒤가 아니라 검산 뒤에
결론을 쓴다.** 이번에는 검산 수단(레포 안의 재현 스크립트) 자체가 없었다.
그래서 `backtest.py --portfolio` 를 만들었고, 앞으로 이 표는 그 출력과
일치해야 한다.

상세 명세는 [strategy.md](strategy.md).

## 작업 히스토리

### 1 · 진단 — 봇이 4개월간 조용히 실패하고 있었다

매매 신호마다 `'str' object has no attribute 'get'` 로 673회 크래시.
원인은 빗썸이 IP 화이트리스트 밖 요청에 `403 NotAllowIP` 를 돌려주는데,
그 오류 응답을 계좌 목록으로 가정하고 순회한 것이었다.

### 2 · 수정 — API 2.0 마이그레이션과 잠복 버그 3건

- 마켓 코드 `BTC-KRW` → `KRW-BTC`. 존재하지 않는 마켓이라 주문이 400 으로 거부되고 있었다
- 시장가 매도 규격 `ord_type=market` + volume. 매수와 같은 형식을 보내 3월 이후 매도가 전부 실패
- 시세 조회를 구 1.0 `/public` 에서 2.0 `/v1/ticker` 로 교체

### 3 · 검증 — 실주문 왕복 테스트

최소 금액으로 매도·매수를 각각 실행해 주문 경로를 확인했다.
매도 0.00011033 BTC (9,998.99원, 수수료 24.99원), 매수 5,000원 (수수료 12.49원).
둘 다 `201 done`. 3월의 `status 400` 이 마켓 코드와 매도 규격 때문이었음이 확정됐다.

### 4 · 정리 — 리팩토링과 저장소 이전

940줄 단일 파일을 8개 모듈로 분리. 과거 신호 계산을 O(n²)에서 O(n)으로,
재시작 시 중복 주문 방지를 디스크 기록으로, 산출물 경로를 스크립트 기준
절대경로로 통일. GitHub private 저장소에 이력 보존하며 푸시.

### 5 · 검증 — 기존 전략 백테스트 6개월 −12.7%

4시간봉 EMA5/13 이 단순보유에 미달. 원인을 분해하니 6년간 962회 회전하며
**자산의 91%를 수수료로 잃는** 구조였다. 이 시점에서 실주문을 껐다.

### 6 · 탐색 — 10개 계열 579개 조합 검증

추세 필터, 평균회귀, 파라미터 스윕, 단기 전략, 신호 스캔, 조절 장치,
동적 배분, ML 두 종류. 실패 방식이 일관됐다 —
**표본을 키우거나 기간을 나누면 사라졌다.**

### 7 · 채택 — 일봉 3신호 + out-of-sample 검증

시간 축(2017~2020)과 파라미터 격자(20칸)를 통과. 종목 축은 부분 통과.

### 8 · 운영 — 알림 전용으로 재정의

판단이 연 6~14회뿐이라 자동매매가 필요 없다는 결론.
매일 09:01 KST 일봉 마감 직후 5단 차트와 목표 비중을 전송하고,
주문은 수동으로 집행한다. 4시간봉 알림은 시세 확인용으로 유지.

### 9 · 규명 — 왜 안 되는지 정량화

신호/잡음 4.1%, 필요 표본 6.4년, 꼬리 6~309,400배, 타임프레임 무관,
기간 단축 무효, 관계의 연간 반전. 위 인사이트 항목이 이 단계의 결과물이다.

## 이 기록에서 틀렸던 것들

10건의 오류가 있었고 **7건을 사용자가 먼저 발견했다.**
공통 원인은 결론을 먼저 쓰고 검산을 나중에 한 것이다.

| 유형 | 내용 |
|---|---|
| 표본 | 거래 1~3회짜리 결과로 전략 순위를 매겼다. 3년에서 1등이던 조합이 6년에서 꼴찌가 되며 드러났다 |
| 귀속 | 노출도를 낮춘 효과를 전략의 성과로 보고했다 |
| 통제 | 비교 도중 EMA 전략의 투입 비중만 50%에서 100%로 바꿔놓고 다른 테스트와 나란히 제시했다 |
| 자릿수 | 회전율×수수료율을 단순곱해 "수수료 240%"라는 불가능한 값을 냈다. 실제 복리 잠식률은 91% |
| 가중 | 국면별 평균의 평균을 내어 전체 평균과 맞지 않았다. 골든크로스 결론이 정반대로 뒤집혔다 |
| 누락 | 같은 규칙을 두 번 보고하며 한 번은 성적 나쁜 3년·1년 구간을 빼고 "전부 통과"라고 썼다 |
| 미발동 | 증액 규칙이 6년간 0~24회밖에 발동하지 않았는데 "효과 없음"으로 결론냈다 |
| **오염** | **채택 전략 표에 SOL 이 섞인 숫자를 6년간 실적으로 실었다** (876% / 1,019%). SOL 은 배분에서 뺀 종목이다. 레포 안에 재현 수단이 없어 반년 가까이 걸러지지 않았다 |
| **영향 미확인** | **단위 버그의 배율(1,390배)만 보고 심각도를 P0 로 올렸다.** 실행해보니 분기가 갈리지 않아 동작에는 영향이 없었다 |
| **셈 없이 어림** | **"400개 전략 조합"이라고 반복해 썼다.** 세어보니 579개였고, 그마저도 대부분은 같은 전략의 파라미터 변형이라 **계열로는 10개**였다. 숫자를 확인하지 않고 규모를 주장한 것이다 |

마지막 세 건은 성격이 같다 — **숫자를 확인하지 않고 결론에 썼다.**
1,390배도, 876% 대 1,019% 도, 400개도, 실제로 세거나 돌려보기 전에는
근거가 될 수 없었다. 앞의 둘은 검산으로, 마지막은 세는 것으로 드러났다.

이후 네 가지를 규칙으로 삼았다.

1. 표에 **기간 · 수수료 · 비교기준**을 항상 명시
2. 비교는 **수수료 0%부터** 시작
3. 표를 만든 뒤가 아니라 **검산 뒤에** 결론을 쓴다
4. **문서에 싣는 숫자는 레포 안의 스크립트로 재현될 것.** 재현 수단이 없으면
   숫자가 틀려도 아무도 모른다 — 이번이 그랬다

## 남는 선택지

예측이 불가능하다는 전제에서, 통제 가능한 것은 **비용 · 노출 · 규율** 셋뿐이다.

- **그냥 보유** — 9년 데이터가 지지하는 유일한 엣지. 대신 −77% 낙폭과 2~4년 침체를 견뎌야 한다
- **보유하되 큰 하락만 줄이기** — 현재 채택한 3신호 전략. 수익은 비슷하고 낙폭은 절반, 판단은 연 6~14회
- **적립식** — 시점 분산. 이 전략과 궁합이 좋았고, 하락 국면에서 원금 방어가 특히 강했다

셋 다 예측을 요구하지 않는다. 그것이 이 기록의 실용적 함의다.
