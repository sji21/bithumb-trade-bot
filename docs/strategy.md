# 전략 명세

일봉 3신호 가중 비중 배분. **알림 전용** — 봇은 목표 비중을 계산해 알리고,
주문은 사람이 수동으로 집행한다.

판단 빈도가 **연 6~14회**뿐이라 자동매매가 필요하지 않다.

검증 과정과 기각된 대안은 [research-log.md](research-log.md) 참고.

## 신호 계산

세 신호가 각자 0 또는 1 을 내고, 가중합이 목표 비중이 된다.

| 신호 | 조건 | 가중 | 역할 |
|---|---|---|---|
| MA20 / MA60 | `MA20 > MA60` | **0.45** | 중기 추세 |
| 슈퍼트렌드 (10, 3.0) | 상승 추세 | **0.35** | 전환점 포착 |
| MA50 / MA200 | `MA50 > MA200` | **0.20** | 장기 레짐 |

```
점수 = 0.45×MA20/60 + 0.35×슈퍼트렌드 + 0.20×MA50/200

점수 < 0.50  →  목표 비중 0%      (전량 현금)
점수 ≥ 0.50  →  목표 비중 = 점수  (55 ~ 100%)
```

모든 지표는 **전일 종가**로 계산한다 (`.shift(1)`). 당일 종가를 쓰면 미래 참조가 된다.

### 가능한 점수 조합

| MA20/60 | 슈퍼트렌드 | MA50/200 | 점수 | 비중 |
|---|---|---|---|---|
| ✓ | ✓ | ✓ | 1.00 | 100% |
| ✓ | ✓ | — | 0.80 | 80% |
| ✓ | — | ✓ | 0.65 | 65% |
| — | ✓ | ✓ | 0.55 | 55% |
| ✓ | — | — | 0.45 | **0%** |
| — | ✓ | — | 0.35 | **0%** |
| — | — | ✓ | 0.20 | **0%** |
| — | — | — | 0.00 | **0%** |

세 신호 중 **최소 두 개**가 켜져야 진입한다. 하나만 남으면 전량 이탈.

### 리밸런싱 밴드

목표 비중과 현재 비중의 차이가 **10%p 미만이면 거래하지 않는다.**
잦은 소액 조정으로 수수료를 낭비하지 않기 위함이다.

**고정 70/30 이 전부 앞섰다.**

## 성과

**비교기준** BTC 70 / ETH 30 단순보유 · **수수료** 편도 0.25%

| 기간 | 전략 | 단순보유 | 전략 MDD | 보유 MDD | 평균 노출 |
|---|---|---|---|---|---|
| 2020-08 ~ 2026-08 (6년) | 876% | 1,019% | **−38%** | −76% | 45% |
| 2022-01 ~ 2026-08 (2021 제외) | **56%** | 9% | **−36%** | −68% | 41% |
| 2023-08 ~ 2026-08 (3년) | 75% | 91% | **−36%** | −58% | 46% |
| 2025-08 ~ 2026-08 (1년) | **−7%** | −46% | **−21%** | −58% | 26% |

**이 전략은 수익을 늘리지 않는다. 낙폭을 줄인다.**
연도별로 보면 대부분의 해에 단순보유보다 뒤처지고, 대폭락이 온 해에 한 번에 되찾는다.
보험료를 매년 내다가 사고 났을 때 받는 구조에 가깝다.

### 감수해야 하는 것

- **신호가 늦다.** 고점 대비 평균 43일, 저점 대비 평균 56일 지연
- **상승장에서 뒤처진다.** 2021년 같은 해에는 확실히 손해
- **횡보장에서 잦은 진입·이탈이 날 수 있다.** 리밸런싱 밴드가 이를 완화

## 운영

### 일봉 리포트

매일 **09:01 KST** (일봉 UTC 00:00 마감 직후) 텔레그램 전송.

종목별 5단 차트:

1. **가격 + MA20/60/200 + 슈퍼트렌드** — 매수 추세는 초록, 매도 추세는 빨강. 전환 시점을 캔들 근처에 표시
2. **볼린저 밴드**
3. **RSI(14)**
4. **거래량**
5. **점수 추이** — 3신호 각각의 on/off 와 합산 점수

본문에는 종목별 점수, 목표 비중, 현재 비중, 리밸런싱 필요 금액이 들어간다.

### 4시간봉 알림

시세 확인용으로만 유지. **매매 판단에 쓰지 않는다.**
4시간봉 기반 전략은 117개 조합을 검증했으나 수수료 0% 에서도 기대값이 음수였다.

### 실행 모드

| `ENABLE_LIVE_TRADING` | `ENABLE_LIVE_SIMULATION` | 동작 |
|---|---|---|
| `false` | — | **현재 설정.** 알림만, 주문 없음 |
| `true` | `true` | 라이브 경로를 밟되 mock 영수증만 기록 |

## 파라미터

`config.py` 기본값. 모두 `.env` 로 덮어쓸 수 있다.

```python
DAILY_FAST, DAILY_MID       = 20, 60      # 중기 이평
DAILY_SLOW_FAST, DAILY_SLOW = 50, 200     # 장기 이평
ST_PERIOD, ST_MULT          = 10, 3.0     # 슈퍼트렌드
W_FAST, W_ST, W_SLOW        = 0.45, 0.35, 0.20
SCORE_FLOOR                 = 0.50        # 진입 하한
REBAL_BAND                  = 0.10        # 리밸런싱 밴드
DAILY_CHART_DAYS            = 180         # 차트 표시 기간
DAILY_HISTORY_DAYS          = 480         # MA200 워밍업 포함 수집량
FEE_RATE                    = 0.0025      # 빗썸 시장가 편도 수수료
```

### 파라미터 민감도

슈퍼트렌드 `period 7~20 × 배수 2.0~4.0` 격자 20칸 전부에서 단순보유 대비 개선.
**뾰족한 최적점이 아니라 고원**이라 과최적화 위험이 낮다.

가중치는 `0.45 / 0.35 / 0.20` 외에 `0.50 / 0.30 / 0.20`, `0.40 / 0.40 / 0.20` 등도
비슷한 성적을 낸다. 중요한 것은 **개별 가중치가 아니라 "최소 두 신호" 라는 구조**다.

## 검증

**out-of-sample (시간축)** 파라미터 선택에 쓰지 않은 2017~2020 구간에서 재현.
BTC 3.30x vs 단순보유 2.86x.

**out-of-sample (종목축)** 대조군 8종 중 3종만 통과. **범용 전략이 아니다.**
BTC·ETH 처럼 유동성이 크고 추세가 오래 가는 종목에서만 작동하는 것으로 보인다.

**파라미터 격자** 20칸 전부 개선 (위 참고).
