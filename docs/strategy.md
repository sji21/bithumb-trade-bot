# 전략 명세

일봉 3신호 가중 비중 배분. **알림 전용** — 봇은 목표 비중을 계산해 알리고,
주문은 사람이 수동으로 집행한다.

비중 조정이 **자산당 연 12회 안팎**(2018~2026 평균 11.6회, 많은 해 17회)이라 자동매매가 필요하지 않다.

지금 믿을 수 있는 숫자는 [review-2026-11.md](review-2026-11.md), 2026-08 의 탐색 기록은 [research-log.md](research-log.md).

## 신호 계산

세 신호가 각자 0 또는 1 을 내고, 가중합이 목표 비중이 된다.

| 신호 | 조건 | 가중 | 역할 |
|---|---|---|---|
| MA20 / MA60 | `MA20 > MA60` | **0.45** | 중기 추세 |
| 슈퍼트렌드 (10, 3.0) | 상승 추세 | **0.35** | 전환점 포착 |
| MA50 / MA200 | `MA50 > MA200` | **0.20** | 장기 레짐 |

```
점수 = 0.45×MA20/60 + 0.35×슈퍼트렌드 + 0.20×MA50/200

점수 < 0.50  →  목표 비중 0%      (전량 현금)
점수 ≥ 0.50  →  목표 비중 = 점수  (55 ~ 100%)
```

모든 지표는 **전일 종가**로 계산한다 (`.shift(1)`). 당일 종가를 쓰면 미래 참조가 된다.

### 가능한 점수 조합

| MA20/60 | 슈퍼트렌드 | MA50/200 | 점수 | 비중 |
|---|---|---|---|---|
| ✓ | ✓ | ✓ | 1.00 | 100% |
| ✓ | ✓ | — | 0.80 | 80% |
| ✓ | — | ✓ | 0.65 | 65% |
| — | ✓ | ✓ | 0.55 | 55% |
| ✓ | — | — | 0.45 | **0%** |
| — | ✓ | — | 0.35 | **0%** |
| — | — | ✓ | 0.20 | **0%** |
| — | — | — | 0.00 | **0%** |

세 신호 중 **최소 두 개**가 켜져야 진입한다. 하나만 남으면 전량 이탈.

### 리밸런싱 밴드

목표 비중과 현재 비중의 차이가 **10%p 미만이면 거래하지 않는다.**
잦은 소액 조정으로 수수료를 낭비하지 않기 위함이다.

## 성과

**비교기준** BTC 70 / ETH 30 단순보유 · **수수료** 편도 0.25% · **리밸런싱 밴드** 10% ·
**체결** 신호 다음 날 종가 · 재현: `python3 evaluate.py --end 2026-11-19`

| 기간 | 전략 | 단순보유 | 전략 MDD | 보유 MDD | 평균 노출 |
|---|---|---|---|---|---|
| 2018-03-06 ~ 2026-11-19 (전체) | 1,314% | 370% | **−42%** | −77% | 44% |
| 2020-08-07 ~ 2026-08-06 (6년) | 551% | 439% | **−40%** | −77% | 46% |
| 2023-11-20 ~ 2026-11-19 (3년) | 66% | 42% | **−36%** | −56% | 49% |

> **2026-11-20 정정.** 이전 판의 표(6년 541% / 430% 등)는 여기 적혀 있던 명령으로
> 재현되지 않았다. 스크립트가 평가 구간 안의 데이터만으로 지표를 계산했기 때문이다.
> 스크립트를 고치고 구간을 고정해 다시 계산했다. 2026-08-06 의 정정이 원인으로 든
> SOL 혼입은 확인된 것이 아니라 추정이었다. 경위는 [재검토 기록](review-2026-11.md).

**위 표의 구간은 모두 전략에 유리한 쪽이다.** 시작일을 30일씩 옮겨 만든 3년 구간 70개 중
전략이 보유보다 수익이 높은 것은 51% 이고, 수익 중앙값은 172% 대 285% 로 보유가 높다.
낙폭은 93% 의 구간에서 전략이 얕다.

**이 전략의 목적은 수익 증대가 아니라 낙폭 축소다.** 그리고 낙폭이 주는 것은
평균 보유 비중이 44% 이기 때문이다 — 같은 비중을 그냥 들고 있어도 낙폭은 −44% 다.
**상승장에서 뒤처지는 것이 이 구조의 정상 동작**이며, 그 대가로 폭락 구간을 덜 맞는다.
같은 비중을 고정한 것보다 수익이 높았던 것(연환산 36% 대 15%, t = 2.2)이 이 규칙이
더한 몫인데, 여러 후보를 본 뒤 고른 전략이라 우연이 아니라고 단정할 수 없다.

### 감수해야 하는 것

- **신호가 늦다.** 고점 대비 평균 43일, 저점 대비 평균 56일 지연
- **상승장에서 뒤처진다.** 2021년 같은 해에는 확실히 손해
- **횡보장에서 잦은 진입·이탈이 날 수 있다.** 리밸런싱 밴드가 이를 완화

## 운영

### 일봉 리포트

매일 **09:01 KST** (일봉 UTC 00:00 마감 직후) 텔레그램 전송.

종목별 5단 차트:

1. **가격 + MA20/60/200 + 슈퍼트렌드** — 매수 추세는 초록, 매도 추세는 빨강. 전환 시점을 캔들 근처에 표시
2. **볼린저 밴드**
3. **RSI(14)**
4. **거래량**
5. **점수 추이** — 3신호 각각의 on/off 와 합산 점수

본문에는 종목별 점수, 목표 비중, 현재 비중, 리밸런싱 필요 금액이 들어간다.

## 파라미터

`config.py` 기본값. 모두 `.env` 로 덮어쓸 수 있다.

```python
DAILY_FAST, DAILY_MID       = 20, 60      # 중기 이평
DAILY_SLOW_FAST, DAILY_SLOW = 50, 200     # 장기 이평
ST_PERIOD, ST_MULT          = 10, 3.0     # 슈퍼트렌드
W_FAST, W_ST, W_SLOW        = 0.45, 0.35, 0.20
SCORE_FLOOR                 = 0.50        # 진입 하한
REBAL_BAND                  = 0.10        # 리밸런싱 밴드
DAILY_CHART_DAYS            = 180         # 차트 표시 기간
DAILY_HISTORY_DAYS          = 480         # MA200 워밍업 포함 수집량
FEE_RATE                    = 0.0025      # 빗썸 시장가 편도 수수료
```

### 파라미터 민감도

슈퍼트렌드 `period 7~20 × 배수 2.0~4.0` 격자 20칸 전부에서 단순보유 대비 개선.
**뾰족한 최적점이 아니라 고원**이라 과최적화 위험이 낮다.

가중치는 `0.45 / 0.35 / 0.20` 외에 `0.50 / 0.30 / 0.20`, `0.40 / 0.40 / 0.20` 등도
비슷한 성적을 낸다. 중요한 것은 **개별 가중치가 아니라 "최소 두 신호" 라는 구조**다.

## 검증

**고르기 전 구간** 2018-03-06 ~ 2020-08-06: 전략 87% 대 보유 −9%, 낙폭 −42% 대 −76%.
(BTC 만 2017-08-17 부터 보면 3.20x 대 2.73x. 이 구간은 앞쪽 200봉의 지표가 온전하지 않다.)

**고른 뒤 구간** 2026-08-07 ~ 2026-11-19: 전략 17% 대 보유 −6%. 석 달 반이라 판단하기에는 짧다.

**가중치** 0.1 단위로 바꾼 36가지 중 채택값은 세 구간 모두 수익 12위다. 근처 값은 비슷하고,
한 신호에 몰면 크게 달라진다.

**확인할 수 없는 것** 이전 판의 "대조군 8종 중 3종 통과", "슈퍼트렌드 격자 20칸 전부 개선"은
코드와 목록이 남아 있지 않아 근거로 쓰지 않는다.
